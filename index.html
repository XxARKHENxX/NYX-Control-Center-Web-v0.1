1. Gerar credencial

    
Cria 32 bytes aleatórios com Web Crypto. A chave não é colocada no código do GitHub, no endereço da página ou nos consoles.

    
    
Nenhuma chave gerada nesta sessão.

  


  

    
2. Guardar recuperação

    
O arquivo de recuperação contém a chave secreta. Guarde-o fora de pastas compartilhadas, não publique no GitHub e não envie seu conteúdo nesta conversa. Quem obtiver essa chave poderá tentar se passar por um dispositivo autorizado quando a autenticação estiver implementada.


    

    
  


  

    
3. Gravar na NYX

    
A janela de cadastro dura 60 segundos. O navegador enviará a chave exclusivamente pela porta USB selecionada.


    

      
      
    

    
Conecte o USB e consulte o estado.

  


  

    
4. Verificação

    
Após uma gravação confirmada, pressione RESET no ESP32 e clique novamente em Consultar estado. O resultado esperado será SEC|PROVISIONED.

    
Aguardando cadastro.

  


  
Esta versão implementa somente o cadastro inicial. Transferência da credencial ao celular, autenticação HMAC, gerenciamento de dispositivos e criptografia BLE obrigatória ainda são etapas futuras.
