# NYX Control Center Web v0.1

Interface de testes para firmware NYX-Link v0.1. Hospede `index.html` via HTTPS (por exemplo, GitHub Pages). Web Bluetooth requer navegador compatível, contexto seguro e gesto do usuário para seleção do dispositivo. Chrome Android e Chrome/Edge desktop são opções comuns; iOS Safari não oferece Web Bluetooth nativo. A interface NÃO implementa criptografia obrigatória, bonding ou autenticação NYX. Não usar comandos sensíveis.

## GitHub Pages
Crie repositório `NYX-Control-Web`, envie `index.html` para raiz, Settings > Pages > Deploy from a branch > main / (root) > Save. Acesse o endereço HTTPS que o GitHub informar. Não hospede chaves de provisionamento no site ou no repositório.
